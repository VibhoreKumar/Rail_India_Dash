# RailVista India — Dashboard (current Gold exports)

Preserves the Routey-inspired charcoal dashboard and historical railway map. **No old Gold data is bundled.**

## 1. Export latest Gold data from Databricks
Your `05_Output` task already writes CSV files into `/Volumes/workspace/default/railway_gold/exports/<dataset>/part-*.csv`.
Download the latest `part-*.csv` for each of:
- overall_kpis
- station_performance
- train_performance
- monthly_performance
- yearly_performance
- station_recovery

Rename them to `<dataset>.csv` and put them inside `data/`, or keep each part file under `data/<dataset>/part-*.csv`. **Use the latest outputs from the same pipeline run.**

## 2. Prepare and run locally (Mac)
```bash
cd RailPulse_Dashboard
python3 -m pip install pyarrow
python3 prepare_data.py
python3 -m http.server 8000
```
Open http://localhost:8000. The preparation script validates presence and non-emptiness and converts current exports into JSON. It does not assert obsolete station/train counts.

## 3. Enable station markers and historical routes
In Databricks run `export_network_geo_databricks.py`, updating `SILVER_TABLE` to your actual clean Silver table. Download `/Volumes/workspace/default/railway_gold/exports/network_geo.json` to `data/network_geo.json`. Refresh the browser.

The popup metrics join Gold station performance on station_code. Selected trains highlight their station stop sequences. Lime connecting lines are schematic, **not exact track geometry**; railway infrastructure tiles are from OpenRailwayMap and require internet. No live train locations are claimed.

## Optional validation audit
If available, convert `validation_audit.parquet` to `data/validation_audit.json` separately; the Data Quality view can otherwise be empty.

## Dashboard visual refresh
- Refined charcoal-and-lime interface with higher contrast, modern navigation, and responsive layouts.
- Historical data coverage strip dynamically reflects the loaded train and station datasets.
- **Export** button downloads the currently selected view's Gold analytics as CSV.
- Map station popups show historical arrival delay and punctuality when `network_geo.json` is available.
- Railway stop connections are schematic, **not live train tracking or actual rail geometry**.

## GitHub / Vercel
This is a static site. Commit the contents of this folder to your dashboard repository.
To deploy on Vercel, set the framework to **Other**, root directory to the folder containing `index.html`, and output directory to `.`.
The site needs the six `data/*.json` files generated by `prepare_data.py` before deployment. Never deploy credentials or private raw data.
